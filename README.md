## The word

> meetmute: talking for a full minute before noticing you were on mute.

69 characters, one line. Written for the judge's brief: "meetmute"
(meeting + mute) names a real gap — the moment you realise you have been
talking to a room that could not hear you — in one clean compound that is
sayable, spellable and memorable, and the definition lands in a single
reading.

## Run

```sh
python3 main.py            # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Local test: run twice into two folders and compare — both runs must write
byte-identical `entry.txt` (69 chars, one line, valid UTF-8).
